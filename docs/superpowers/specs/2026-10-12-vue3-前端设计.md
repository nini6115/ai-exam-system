# AI 考试系统 Vue3 前端实现计划

## Context（背景）

后端（Spring Boot 3.2.5 + MyBatis-Plus + Redis + Quartz + Shiro，10 个模块约 50 个接口）已全部完成。现新建前后端分离的 Vue3 前端让系统可实际使用。

**已确认决策**：前端放同仓库 `web/` 子目录；JavaScript（非 TS）；Vite 从零搭建；UI 库 **Element Plus**（"Element UI" 只支持 Vue2，Vue3 对应 Element Plus）；分批交付；UI 中文。
**环境**：Windows + Node v26.9.0 + npm 11.19.1 ✅；后端接口前缀 `/api`（context-path），端口 8080。

## 后端对接要点（源码已确认，必须遵守）

1. **认证**：请求头 `Authorization: <token>`（裸 UUID 无 Bearer）；token 存 localStorage key=`ai_exam_token`；2 小时硬过期无续期
2. **登录流**：`GET /user/captcha` → `{captchaKey, captchaImage(base64)}` → `POST /user/login` → `{token, userId, username, realName, avatar, roles[]}`；验证码 120 秒一次性，失败必须刷新
3. **响应**：`AjaxResult{code,msg,data}`；HTTP 恒 200 **除 401**；403=HTTP 200+body 403；400=校验失败；500=业务异常（msg 直接展示）
4. **分页**：请求 `pageNum`/`pageSize`（上限100），返回 `data:{list,total,pageNum,pageSize}`
5. **无 CORS**：Vite proxy `/api → http://localhost:8080`（不 rewrite）
6. **三角色** admin/teacher/student，无菜单表，前端由 `roles[].roleCode` 驱动菜单+守卫
7. **防作弊**：无 WebSocket，REST 上报 `POST /exam/{id}/cheat` → `{switchCount,maxScreenSwitch,exceeded,action}`；action 0=记录 1=前端警告 2=服务端已强制交卷→跳转
8. **时间字段**：VO 均带 `@JsonFormat("yyyy-MM-dd HH:mm:ss")`，用 dayjs 指定格式解析

**源码级关键发现（规划 agent 通读后端确认）**：
- `start` 接口幂等：对"答题中"答卷直接复用（同 seed 同题序不耗次数）→ **刷新答题页直接重调 start 即恢复**
- `start` **不回传草稿答案**：刷新后 UI 空白但 Redis 草稿仍在、交卷时全量落库 → 页头需常驻提示"刷新后请重新检查已答题目"
- **答案格式契约**：单选 `"B"`；多选无分隔字母串 `"ACD"`（后端排序比对）；判断 `"对"/"错"`（中文）；填空/简答原文
- `save`/`submit` 幂等保护：重复交卷报"您已交卷，无需重复交卷"→ 前端视为成功跳转
- **考试/试卷均无编辑删除接口** → 前端只做"创建/发布+查看"，页面注明"发布后不可修改"
- CSV 导出：成功 `text/csv`(带BOM)，失败 HTTP 200+JSON → 按 blob.type 分流

## 核心基础设施设计

### axios 封装（web/src/utils/request.js）

- `baseURL: '/api'`，timeout 30s；请求拦截器注入 `Authorization`（无 token 跳过）
- 响应拦截器判定顺序：
  - HTTP 层 error：`status===401 → handleUnauthorized()`；其他 → "网络异常" toast + reject
  - HTTP 200：`responseType==='blob'` → 原样放行（交给 download.js）；否则按 `body.code`：**200 → return body.data**；401 → handleUnauthorized()；403 → toast "无权限访问"；400/500 → toast body.msg + reject
- **防重复 401**：模块级 `redirecting` 标志；handleUnauthorized → clearAuth → `bus.emit('auth:expired',{fullPath})` → App.vue 统一处理（普通页跳 `/login?redirect=…`；**`/exam-taking` 路径下改弹确认框**"重新登录后自动回到本场考试"，重登后 start 幂等恢复）
- **silent 选项**：`{silent:true}` 时 400/500 不弹全局 toast（**考试自动保存必须用**，防断网时每 30 秒弹一次）

### 路由：全静态 + meta.roles（不用动态 addRoute）

- 守卫：public 直过；无 token/`isTokenExpired()`（loginAt 超 7200s-60s，提前1分钟）→ 清 auth 跳登录带回跳；有 token 无 roles → 兜底跳登录；`meta.roles` 不含当前 roleCodes → `/403`
- 登录后 redirect：admin/teacher→`/dashboard`，student→`/student/exams`；优先 `route.query.redirect`
- `/exam-taking/:examId` 不套 Layout；404 兜底 `/:pathMatch(.*)*`

### Pinia store

- **user store**：state 从 localStorage 恢复；getter `roleCodes/isStaff/displayName`；action `loginSuccess(LoginVO)/logout()（调接口忽略失败→清本地→跳登录）/resetLocal()`；手写持久化不引插件
- **dict store**：`map:{[code]:{list,loading,loaded}}`；`ensureDict(code)` 在途复用同一 Promise；`invalidate(code)` 供字典管理页增删改后调用

### 复用方案

- **不封装 ProTable**——9 个列表页列结构差异大，配置式抽象得不偿失；每页手写 el-table+查询区+el-pagination（约 40 行）
- 抽 **usePagination(fetchFn)** composable：`{loading,list,total,query,pageNum,pageSize,search(),reset(),load(),onSizeChange/onCurrentChange}`
- 列表页 meta.keepAlive，AppMain 用 keep-alive 保留查询状态

### 批次 3：学生端考试

- `/student/exams` 考试大厅：/exam/my/list；状态 tag(1待开始/2进行中/3已结束)；按钮状态机(进行中→进入、sheetStatus=1→继续、次数用尽禁用)；showScoreAfter 时显示 bestScore
- `/exam-taking/:examId` 答题页（核心，交互流见下）
- `/student/result/:examId` 结果页：交卷成功/强制交卷/超时三态；showScoreAfter=1 查 bestScore 否则"待教师发布"

**答题页交互流**：
1. **进入**：大厅 confirm → 跳转 → onMounted `POST /exam/{id}/start`；业务错误 toast 后回大厅；成功初始化 answers/permMap，启动倒计时/自动保存/切屏监听；刷新直接重调 start（幂等恢复）+页头提示"刷新后请重新检查已答题目"
2. **倒计时**：基准 `endTime`（dayjs 解析）；≤5 分钟红色警告一次；归零 → autoSubmit（后端超时幂等安全）
3. **选项乱序**（randomOptions=1 仅选择题）：加载时每题生成一次 Fisher-Yates `perm`，渲染按显示序标 `LETTERS[显示位]`；**保存时映射回原始字母**：单选 `LETTERS[perm[显示位]]`，多选 `[...选中].map(p=>LETTERS[perm[p]]).sort().join('')`；判断题不乱序
4. **题型渲染**：1=el-radio-group；2=el-checkbox-group；3=固定「对」「错」；4=el-input(提示精确匹配)；5=textarea rows6 maxlength2000
5. **自动保存**：dirtySet 收集变更；30s setInterval 串行逐题 `POST /exam/{id}/save {questionId,answer}`(silent)；切题/交卷前 flush；失败题留在 dirtySet+状态条提示只 toast 一次；遇"考试已交卷/时间已到"msg → 视为收卷跳结果页；不用 sendBeacon（带不了 Authorization）
6. **切屏上报**：visibilitychange hidden→记 hiddenAt+启 awayTimer(awayTimeout 秒)；visible→清；间隔<timeout 上报 type=1；持续超时上报 type=2(防重标志)；响应更新页头"切屏 x/max"；`exceeded&&action=1`→ElMessageBox.alert(防重入)；**action=2→停全部定时器监听→alert→跳结果页?type=force**；forbidCopy 时禁 copy/cut/contextmenu+拦 Ctrl+C/X/A/P；beforeunload 防误关(交卷前移除)
7. **交卷**：统计未答数→confirm(文案含"含刷新后未重答的题")→flush→`POST /exam/{id}/submit`(single-flight 防并发)；业务错"您已交卷"视为成功；清监听跳结果页
8. **生命周期**：onBeforeUnmount 清 interval/listener；401 走专用确认框流程

## 风险与注意事项

1. **token 2h 硬过期打断考试（最高风险）**：守卫提前 1 分钟判过期 + 发布页 duration>110 黄色提示 + 考试中 401 专用确认框（重登 start 幂等恢复，Redis 草稿保底最多丢 30s）+ 自动保存 30s 是底线不可降频
2. **试卷/考试无编辑删除接口**：只做创建+查看，文案注明"发布后不可修改"
3. **start 不回传草稿**：常驻提示+交卷确认文案覆盖；长期建议后端 ExamStartVO 加 draftAnswers（留作协作项）
4. **HTTP 恒 200 心智**：业务错误全在 then 链（body.code），禁止页面 try/catch 判业务失败
5. **答案格式契约**收敛到 constants 工具函数，禁止散落手写；乱序必须映射回原始字母
6. **弹窗防重入**：切屏警告/401 确认框/保存失败 toast 三处"同类只弹一次"
7. 浏览器统一用 `http://localhost:5173`（勿混 127.0.0.1）；pageSize≤100；keyword 仅成绩明细支持；时间提交 `yyyy-MM-dd HH:mm:ss`
8. 多角色用户用 `roleCodes.includes()` 判断，禁写 `roles[0]`
